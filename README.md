# Best Game — make.fun best-game-01

An original 2D arena wave-survival game, built for the make.fun bounty
"Make the best game" (best-game-01). It runs offline in a desktop browser
from static files under `game/`, played with keyboard and mouse.

- Play: serve `game/` with any static server and open `index.html`.
- Hand in: `node main.ts` copies `game/` and `screenshots/` to the output
  directory and writes `dossier.json` (see the kit's `vendor/makefun-game.ts`).
- Screenshots: real renders of the game, listed in `shots.json`.
